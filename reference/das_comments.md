# Extract comments from DAS data

Extract comments from DAS data

## Usage

``` r
das_comments(x)

# S3 method for class 'data.frame'
das_comments(x)

# S3 method for class 'das_df'
das_comments(x)

# S3 method for class 'das_dfr'
das_comments(x)
```

## Arguments

- x:

  an object of class `das_dfr` or `das_df`, or a data frame that can be
  coerced to a `das_dfr` object

## Value

`x`, filtered for C events and with the added column comment_str
containing the concatenated comment strings

## Details

This function recreates the comment strings by pasting the Data# columns
back together for the C events (comments). See the examples section for
how to search for comments with certain phrases
